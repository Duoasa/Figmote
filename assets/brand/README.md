# Figmote brand assets

- `github-header.png`: wide README banner.
- `social-preview.png`: 1280 × 640 PNG for GitHub repository social previews, adapted from the README banner with the same wordmark, subtitle and orange cursor / blue selection-frame artwork.
- `figmote-logo.png` / `figmote-logo.svg`: project logo.
- `plugin-art.png` / `plugin-art@2x.png`: local companion illustration.

To update the repository link preview, upload `social-preview.png` under **Settings → General → Social preview**. Committing the image alone does not change GitHub's preview setting.
